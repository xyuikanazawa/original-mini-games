# Original Mini Games — browser port

Playable browser build of **Original Mini Games** (VD Productions, 2006 freeware).

- Click **Play**, then click the **START O.M.G** logo.
- 12 games available by default; 3 more unlock through play.
- 1–4 local players.

This is a fan decompilation/port for personal study and preservation. The original game is freeware by Philip Alexander Wallin / VD Productions. The browser runtime is [Instance](https://github.com/groverburger/instance) (MIT), a clean-room GameMaker 8.1 implementation compiled to WebAssembly.
